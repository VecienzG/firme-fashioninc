# Firme email FASHION.INC

Pagina di installazione: https://vecienzg.github.io/firme-fashioninc/

## Modificare una firma
1. Modifica `config.json` (nomi, ruoli, numeri, email, link social).
2. Esegui `python3 build.py`.
3. Fai commit e push: GitHub Pages aggiorna la pagina in 1-2 minuti.

Le immagini (`img/`) sono servite da GitHub Pages: non rinominarle e non cancellare il repo,
altrimenti logo e icone spariscono dalle firme già installate.
